        Two maps, and what each one is

        • Live map (top): served by the ValheimOne BepInEx plugin running on your server, on port 8790. It re-draws from your world seed and updates in real time — player positions, and optionally ships, carts, portals and tombstones. This is the one to use while the server is running.
        • Offline map (below): generated in your browser from the world seed by the third-party site valheim-map.world. It needs no mod and works with the server stopped, but it is static — no players.
        • Player dots depend on in-game sharing. ValheimOne respects each player's "visible to other players" map setting by default, so a player who has switched that off will not appear.
        • Your live map is publicly reachable at http://<server-ip>:8790 while the server runs — anyone who knows the address can view it. Player names are hidden from that public view by default. Set an AccessToken in valheimone.cfg if you want it locked down.
