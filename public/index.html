        What Valheim actually reads

        These are the raw files from savedata/. They are the source of truth for admin rights — the API view above can disagree with them. One ID per line, in [Platform]_[UserID] form (e.g. Steam_76561197960287930), copied from the in-game F2 panel or looked up at steamid.io . Restart the server after editing.

        Worlds

        Valheim stores each world as a folder in savedata/worlds_local/. The World name setting must match a folder exactly — if it does not, the server generates a brand new world under that name instead of failing. Change it under Server settings.
